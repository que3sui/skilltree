# 校园共享单车调度建模（课程设计）

数学建模课程设计：用历史租借数据估计各时段需求，给出调度建议。

## 问题

共享单车在宿舍区早高峰缺车、教学区晚高峰堆积。给定租借/归还流水，
估计各站点净流量随时间的变化，并对重点站点给出早晚高峰的调度量建议。

## 数据

`data/raw.csv`：**三天流水节选（30 条，课程示例数据；正式作业使用完整两周流水）**，
含一处真实的脏数据（站点名空格变体）供清洗逻辑处理。
`src/clean.py` 产物 `data/clean.csv`：剔除重复记录与闸机故障时段，按 10 分钟聚合。

## 方法

1. `src/clean.py`：清洗与聚合（剔除异常、缺失时段前向填充并计数）。
2. `src/fit.py`：对每个站点拟净流量的傅里叶基（1 天/半天周期），最小二乘求解；
   **按时间顺序取后半段做留出验证**，报告残差。
3. `src/plot.py`：绘制拟合曲线与残差图，输出 `figs/fit.png` 与 `figs/residual.png`。
4. `paper.md`：摘要、模型假设、结果与调度建议（正式报告随作业提交）。

## 运行

```bash
python src/clean.py && python src/fit.py && python src/plot.py
```

依赖：Python 3.9+，numpy、matplotlib。
